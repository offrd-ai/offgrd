## BLOCK 3 — SUNDAY: THE PLAN  *(new)*

```
Sunday morning, the scout becomes a game plan.

Pull plays from your book or draw new ones — animated, in your own terminology — and build the attack against each look they showed. And here's the part that changes your week: every play in the plan is testable the moment you save it.

Assign the tests Sunday night. Your roster is studying the plan before Monday's practice.
```

## BLOCK 4 — MON–THU: THE PROOF  *(new)*

```
All week, the tests tell you what actually stuck.

Reads, coverage ID, assignments — graded, by player, by position group. Drill what the scores expose. Trim what they've mastered. The scout team runs their actual plays off cards nobody had to draw.

By Thursday, who's ready isn't a feeling. It's a number. And Friday's grades become next Monday's focus.
```

## BLOCK 5 — THE PROGRAM, AND THE NEXT LEVEL  *(new)*

```
Around all of it, the Coaches Hub runs the program — roster, depth chart, schedule, messaging — one place, every coach.

And the film you've been charting all season? That's your kids' recruiting film. The OFF-ROAD recruiting stack is built in — the same system that calls Friday night helps get your players to the next level.
```

**Pronunciation check before a full render:** "OFFRD" will hit the same consonant-cluster problem as OFFGRD. Try `OFF-ROAD` first (typed spelling only — captions will read OFFRD); if the take says "off-road" too literally, record that one word separately. Test it the way we tested OFF-GRID.

This is the only claim in the category nobody can answer — every competitor ends at the scoreboard. Positioning rails that go with it, agreed with Matt:
- **Never promise wins.** The line is "you'll never be out-prepared" — more right calls, a roster that knows the plan. Coaches complete the preparation→wins sentence themselves.
- **Never invent a time-saved total.** Publish the task ledger instead (cards hand-drawn → built from the chart; self-scout typed Saturday → written live; tendencies on a legal pad → computed at import; tests hand-made → generated from the saved plan). Every line checkable = the unverifiable ones get believed. Future site section: "Your week, before and after."

The Block 4 loop line lands right before Block 5, so the film closes: week pays off Friday → program runs around it → film becomes the kids' future → Friday night → wifi dies, keeps working → lockup.
